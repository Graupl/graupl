# Breadcrumbs

The breadcrumb component provides a set of classes to show where a page sits in a site's hierarchy.

Breadcrumbs implement the spec found in the [ARIA Authoring Practices Guide](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/).

## Base classes

Use `.breadcrumb` on an ordered list inside a labelled navigation landmark. Add `.breadcrumb-item` to each list item and `.breadcrumb-link` to each link. Add `aria-current="page"` to the current page link, or optionally to its list item if the current page is plain text.

## Collapsible breadcrumbs

Graupl provides a feature for breadcrumbs that is not part of the ARIA Authoring Practices Guide, collapsible breadcrumbs. This allows breadcrumb trails to take up less space on smaller screens.

Put a `.breadcrumb-toggle` button in its own `.breadcrumb-item` before the items you want to collapse. Give the button an accessible name. When the trail is collapsed, the items after the button are hidden except for the last item. Once expanded, the full trail is visible and the button is hidden.

::: info Note
By default, the trail can collapse at viewport widths of 856px and below. The preview sets `mediaQuery` to `"(min-width: 0px)"` so you can expand the trail at any viewport width.
:::

## Initialization

A basic breadcrumb trail works without JavaScript. To enable the collapsible trail, run the breadcrumb generator after the markup is in the DOM.

```js
import generateBreadcrumbs from "@graupl/core/breadcrumb/generator";

generateBreadcrumbs();
```

The generator finds the toggle inside `.breadcrumb`. Initialization sets the button's `aria-controls` to the trail's ID and updates `aria-expanded` as the trail expands or collapses.

Breadcrumb items show and hide immediately by default. To enable item fades, pass `transitionClass: "transitioning"` in the generator’s `options` object. The fade uses `transitionDuration`.

## Variants

By default, no theme variants are generated.

If you are [compiling your own version of Graupl](../compiling-graupl.md), you can set the breadcrumb module’s `$themeable` variable to `true` to generate the `.primary`, `.secondary`, and `.tertiary` variants. Add a variant class alongside `.breadcrumb` or to an element inside it.

## Installation

### Stylesheets

The full `graupl.css` stylesheet includes these styles. To load them separately, use one of the options below.

::: code-group

```html [Local]
<link rel="stylesheet" href="./dist/css/component/breadcrumb.css">
```

```html [CDN]
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@graupl/graupl@1.0.0-beta.58/dist/css/component/breadcrumb.css">
```

```scss [Sass]
@use "pkg:@graupl/core/component/breadcrumb.scss";
```

:::

### JavaScript

For a page that uses this component, include its generator script below. It finds and initializes matching markup when the page loads. If you already load the full `graupl.js` bundle, it runs the generator for you. To call the generator yourself, see [Initialization](#initialization).

::: code-group

```html [Local]
<script defer src="./dist/js/breadcrumb.js"></script>
```

```html [CDN]
<script defer src="https://cdn.jsdelivr.net/npm/@graupl/graupl@1.0.0-beta.58/dist/js/breadcrumb.js"></script>
```
