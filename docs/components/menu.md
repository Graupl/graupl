# Menus

The menu component provides a set of classes to style lists of links and submenus. Use the [Navigation component](./navigation.md) to add interactive toggles and a responsive navigation layout.

## Base classes

The `.menu` class lays out a list of links in a row by default. Add `.menu-item` to each list item and `.menu-link` to its link.

<live-example :source-code="exampleMenu" />

## Submenus

Use `.submenu` on a nested list to stack its items vertically. Add `.show` to display the submenu or `.hide` to hide it.

::: info Note
Submenus normally open below their parent item. The preview uses `.position-static` to keep the open submenu inside the example.
:::

<live-example :source-code="exampleSubmenu" />

## Interactive submenus

Menu styles work without JavaScript, but interactive expanding and collapsing of submenus does not. Follow the [Navigation initialization instructions](./navigation.md#initialization) to set it up.

## Variants

By default, no theme variants are generated.

If you are [compiling your own version of Graupl](../compiling-graupl.md), you can set the menu module’s `$themeable` variable to `true` to generate the `.primary`, `.secondary`, and `.tertiary` variants. Add the variant class alongside `.menu` to style the list and its submenus. If the menu is inside a navigation, see [Navigation variants](./navigation.md#variants) for how the two sets of variants work together.
