# Community

Graupl is part of Accessible Ecosystem. We aim to make the web more accessible and to write code and documentation that people can understand and maintain.

Read the [contribution guidelines](./contributing.md) for setup, checks, and the pull request process.

- [AI contribution policy](./ai-contributions.md) explains disclosure and required human review.
- [Accessibility policy](./accessibility.md) describes our goals, testing limitations, and how to report an issue.
- [Code of conduct](./code-of-conduct.md) sets expectations for participation and explains how to report concerns.
- [Security policy](./security.md) lists supported versions and the vulnerability reporting process.
- [Commit guidelines](./commit-guidelines.md) explain the commit format.
