# Introduction

Graupl gives you styles and interactive components for building a website or web application. Start by loading its CSS, then use the classes you need in your HTML. Some styles, such as the default styles for links and form fields, apply as soon as the stylesheet loads.

- **Base styles** cover elements such as buttons, links, form controls, and tables.
- **Components** provide styles for patterns such as badges and cards. Interactive components such as accordions and tabs also provide JavaScript for their behavior.
- **Utilities** let you adjust specific parts of a design with classes for spacing, layout, typography, and color.

Follow the [Quick Start](./quick-start.md) to set up Graupl in your project.

## Accessible Ecosystem

Graupl is part of Accessible Ecosystem. Its interactive components build on [Accessible Ecosystem Core](https://github.com/Accessible-Ecosystem/core) for shared JavaScript behavior.

See the [community guidelines](/community/) for how to contribute or report an issue.
