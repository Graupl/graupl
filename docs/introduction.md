# Introduction

Graupl is a collection of Sass utilities and components that can be used to build a website or web application. It is designed to be flexible and customizable, so you can use as much or as little of it as you need.

Graupl is part of Accessible Ecosystem. Its JavaScript components extend [Accessible Ecosystem Core](https://github.com/Accessible-Ecosystem/core). Graupl provides the styles and behavior specific to its components. Read the [community guidelines](/community/) to contribute or report an issue.
