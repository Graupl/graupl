# Tables

The table base component provides a set of classes to style tables consistently across your application. It includes various states and modifiers to handle different table types and interactions. The selectors `table`, `caption`, `th`, `td`, `tr`, and `tbody` are generated by default.

Tables are themeable, which means that it is a component in which you can turn themeing off by setting the variable `$themeable: false` or on by setting `$themeable: true`. Themeing is true by default for tables.

## Base class

The `.table` class is the base class for all table styles.

## Variants

Variants for tables can be turned on by setting `$themeable: true`, and can be turned off by setting `$themeable: false`.

Themeing is true by default for tables.

<br>

There are 3 table colour variants provided by default: `.primary`, `.secondary` and `.tertiary`.

## Modifiers

There are also many classes that help to customize your table:

| Class Name | Property|
| --- | --- |
| `.bordered`| make the table component bordered |
| `.collapsed`| make the table component's border collapsed |
| `.striped-columns`| make the table component's columns striped |
| `.striped-rows`| make the table component's rows striped |
| `.hoverable`| make the table component's rows change colour on hover |
| `.highlight`| highlight table components |
| `.responsive-table`| make the table component responsive |
