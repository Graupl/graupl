# Forms

This module provides the base styles for form components, such as inputs, textareas, selects, labels, and fieldsets.

Forms are themeable, which means that it is a component in which you can turn themeing off by setting the variable `$themeable: false` or on by setting `$themeable: true`. Themeing is true by default for forms.

## Base class

## Variants

Variants for forms can be turned on by setting `$themeable: true`. Themeing is true by default for forms.

Variants can be turned off by setting `$themeable: false`.
