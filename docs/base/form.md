# Forms

This module provides the base styles for form components, such as inputs, textareas, selects, labels, and fieldsets.

## Base class

The following selectors are generated by default: `input`,`textarea`,`select`, `label`, and `fieldset`.

<form class="display-flex flex-col g-3" id="example-form">
  <fieldset>
    <legend>Fieldset Legend</legend>
    <label id="first-input-label" for="first-input"> Input </label>
    <input type="text" id="first-input" placeholder="Type here" />
  </fieldset>
  <fieldset>
    <label id="first-textarea-label" for="first-textarea"> Textarea </label>
    <textarea id="first-textarea" placeholder="You type things here"></textarea>
  </fieldset>
  <fieldset>
    <label id="first-select-label" for="first-select"> Select </label>
    <select name="colours" id="first-select">
      <option value="purple">Purple</option>
      <option value="red">Red</option>
      <option value="blue">Blue</option>
      <option value="green">Green</option>
    </select>
  </fieldset>
</form>

## Variants

There are 4 form variants provided by default: `.primary`, `.secondary`, `.tertiary`, and `.link`.

<div class="display-flex g-3 flex-wrap">
  <form :class="[$style.form, $style.primary]">Primary Form</form>
  <form :class="[$style.form, $style.secondary]">Secondary Form</form>
  <form :class="[$style.form, $style.tertiary]">Tertiary Form</form>
  <form :class="[$style.form, $style.link]">Link Form</form>
</div>

```html
<form type="form" class="form primary">Primary Form</form>

<form type="form" class="form secondary">Secondary Form</form>

<form type="form" class="form tertiary">Tertiary Form</form>

<form type="form" class="form link">Link Form</form>
```
